# 首批分类体系（taxonomy）

生成日期：2026-09-27。本文记录第一批 598 篇笔记的大类定义、边界规则与执行记录。分类结果保存在 `data-seed/categories-seed.json`（稳定 ID + 逐条理由），生产库首次初始化时导入；之后的任何人工调整保存在运行数据目录的 `overrides.json`，优先级永远高于首批结果。

## 分类原则

- 每篇一个主类，按笔记的主要用途归类；原有细碎 tags 原样保留，用于搜索与详情展示，不改动源数据。
- 类别 ID 稳定（英文），中文名称可调整；改名不影响关联。
- 边界冲突时按"内容主题优先、创作工具其次"判断：例如"用 AI 生成国画"主题是国画，归书画；"用 AI 做网站"主题是 AI 编程，归 AI 与编程。

## 边界判定记录

- **AI 生成国画**（如"用 AI 打开千里江山图"、"AI 国画山水写生"）：主题是国画作品 → `shuhua`。
- **AI 创作玩法**（AI 生图新玩法、AI 把名画变电影、AI 视频教程、AI 修图）：主题是 AIGC 创作方法 → `design-aigc`。
- **AI 编程**（Codex/Claude Code/工作流/知识库搭建）：→ `ai-programming`；其中 Codex+Blender 做数字 3D 内容 → `design-aigc`。
- **3D 边界**：实体制造（打印机、拓竹、打印件）→ `maker-digital`；数字 3D（建模、场景、three.js）→ `design-aigc`。
- **美院内容**：国画/山水示范与临摹教学 → `shuhua`；考研资讯、艺考政策 → `language-learning`。
- **壁纸**：古画壁纸（鹊华秋色文观壁纸）以国画为源 → `shuhua`；新中式/进士及第等通用壁纸套图 → `design-aigc`。
- **文房与文玩**：砚台、印谱、唐笔、折扇等 → `shuhua`；茶器紫砂 → `life`。

## 首批分类执行方式与复核

1. 解析全部 598 篇的标题、tags 与正文摘要（`server/reader` 解析快照）。
2. 通读全部 598 条"标题 + 标签"，从内容分布归纳出上述 6 类。
3. 以关键词规则（标题与标签、优先级排序）+ 49 条人工复核完成批量分配，每条记录命中理由（见 seed 文件 `rationale` 字段）。
4. 校验：598 个 resourceId 全覆盖、无重复分配、无非法类别 ID；6 类合计 272+107+55+41+53+70 = 598。
5. 全量逐条人工审查了规则输出（598 行），对 20 处误判与 23 处规则未命中逐条人工修正；规则输出与人工判定清单保留在 `scripts/classify.mjs`。
6. 抽查：书画、AI、生活各类均超过 40 条逐条过目；全部 6 类的代表条目在审查过程中直接阅读确认。

## 后续新笔记

刷新新增的笔记不在首批映射中，自动进入"未分类"；可在网页详情中手动指定主类，或在后续会话中由 agent 按同样规则批量整理。人工修改永远优先于任何批量结果，刷新不会覆盖 `overrides.json`。
