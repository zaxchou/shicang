# 分类体系（taxonomy）

生成日期：2026-09-28（**按内容重新整理版**，取代 2026-09-27 初版）。本文记录六个大类的定义、边界规则与执行记录。分类结果保存在 `data-seed/categories-seed.json`（稳定 ID + 逐条理由），生产库首次初始化时导入；之后的任何人工调整保存在运行数据目录的 `overrides.json`，优先级永远高于首批结果。

## 分类原则

- 每篇一个主类，按笔记的**主要用途**归类；原有细碎 tags 原样保留，用于搜索与详情展示，不改动源数据。
- 类别 ID 稳定（英文），中文名称可调整；改名不影响关联。
- 内容主题优先于创作工具：**AI 生成国画**归书画（主题是国画）；**AI 生图/视频/3D 创作玩法**归设计与创作；**AI 工具与编程**归 AI 工具。

## 重要边界规则（本次整理逐条验证）

- **国画优先于 AI**：「AI 打开千里江山图」「AI 国画写生」等以画作主题为主的 → 书画（用千里江山/古画/王希孟等锚点识别）。
- **AI 视觉创作 → 设计与创作**：AI 生图/AI 视频/AI 音频/运镜/变装/名画变电影等创作玩法标题**前置**规则，优先于书画标题（修复「洛可可油画运镜」「名画变电影」误入书画）。
- **AI 编程与工具 → AI 工具**：Claude/Codex/博士用法、AI 学习方法、「学习 AI」等 → AI 工具（修复「如何学习 AI」「Claude 用法」被学习类抢走）。
- **学习类锚点收紧**：考研/英语/留学/申请/硕士/大学/数学 → 学习语言；移除宽泛词（博士/科研/文献/古诗/学习），避免抢走 AI 工具笔记。
- **数码硬件按物理实体**：3D 打印/拓竹/PCB/评测/家电/数码 → 数码硬件；标题含「手机/平板」的壁纸与随拍**不**归数码（改由壁纸/摄影标签分流）。
- **单字陷阱修复**：移除裸「松」（误伤轻松/松弛）、裸「竹」（误伤拓竹）、裸「狗」（误伤机器狗 MIT）、裸「打工/收藏/音乐」等标题词。
- **摄影分流**：旅行/随拍摄影（黄山、极简构图、黑白摄影）→ 生活；摄影技巧、人像摄影教程 → 设计与创作；相机选购/摄影器材 → 数码硬件。
- **无标题/不可判断**条目暂归生活并在理由中注明，可人工调整。

## 首批分类执行方式与复核

1. 解析全部 598 篇的标题与 tags（`server/reader` 解析快照）。
2. 通读全部 598 条，按上述边界设计**标题规则 + 标签规则 + 人工表**三层分类器（`scripts/classify.mjs`）。
3. 输出全量 598 行复核清单逐条审查；共 4 轮规则迭代，修正 30+ 处误判（详见 git 历史中的 classify.mjs），人工表 20 条。
4. 校验：598 个 resourceId 全覆盖、无重复分配、无非法类别 ID；六类合计 269+105+65+69+49+41 = 598。
5. 每条记录命中理由（seed 的 `rationale` 字段）；最终全量清单可随时用 `node scripts/classify.mjs` 重新生成到 `.local/classify-review.txt`。

## 后续新笔记

刷新新增的笔记不在首批映射中，自动进入"未分类"；可在网页详情中手动指定主类，或由 agent 按本节规则批量整理。人工修改永远优先于任何批量结果，刷新不会覆盖 `overrides.json`。
